# 🍕 Pizza Sales Analysis

## 📊 Project Overview

This project analyzes pizza sales data to identify key sales trends,
product performance, customer ordering patterns, and revenue drivers.

The analysis was performed using SQL Server and Power BI.

---

## 🎯 Business Objectives

The main objectives of this project are to:

- Analyze overall sales performance
- Identify top and bottom-performing pizzas
- Analyze sales by pizza category
- Analyze sales by pizza size
- Identify peak ordering periods
- Understand daily and monthly sales trends
- Identify key revenue drivers
- Create an interactive Power BI dashboard

---

## 🗂️ Dataset

The dataset contains pizza order transaction data with the following
key fields:

| Column | Description |
|---|---|
| pizza_id | Pizza transaction identifier |
| order_id | Order identifier |
| pizza_name_id | Pizza product identifier |
| quantity | Quantity of pizzas sold |
| order_date | Date of order |
| order_time | Time of order |
| unit_price | Price per pizza |
| total_price | Total transaction value |
| pizza_size | Size of pizza |
| pizza_category | Pizza category |
| pizza_ingredients | Ingredients used |
| pizza_name | Pizza name |
